# Prerequisites (`kaggle-app-hosting`)

- **Local Tools**: Python >= 3.10, `kaggle` CLI, `bash`.
- **Kaggle Environment**: CPU-only (`enable_gpu: false`, `enable_tpu: false`, `enable_internet: true`).
- **Credentials**: `KAGGLE_API_TOKEN` or `kaggle.json` (for Private Dataset sync), `TUNNEL_TOKEN` (for Named Tunnel).
