# Prerequisites (`kaggle-notebook`)

- **Local Tools**: Python >= 3.10, `kaggle` CLI >= 1.6 / 2.x, `curl`, `bash`.
- **Kaggle Environment**: Tesla T4 x2 (32 GiB VRAM), Internet `On`, GPU `On`.
- **Credentials**: `~/.kaggle/kaggle.json` or `KAGGLE_API_TOKEN`, Hugging Face repo access (optional `HF_TOKEN`), Cloudflare Named Tunnel token (`TUNNEL_TOKEN`).
