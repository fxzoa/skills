# Prerequisites (`vm-docker-deploy`)

Before executing `vm-docker-deploy`, ensure the following environment requirements are met:

## 1. Local Machine Requirements
- **Python**: `>= 3.10`
- **Google Cloud CLI (`gcloud`)**: Installed and authenticated (`gcloud auth login` or active ADC).
- **SSH Client**: Standard OpenSSH client (`ssh`, `scp`) available in PATH.
- **SSH Key**: `~/.ssh/google_compute_engine` generated by `gcloud compute ssh`.

## 2. Remote VM Requirements
- **OS**: Ubuntu 22.04 LTS / Debian 11+ (GCE instances).
- **Network**: Outbound Internet access to download Docker packages and container images.
- **Firewall**: Incoming SSH (TCP port 22) allowed from `0.0.0.0/0` or the operator's IP.
- **Compute Sizing**: e2-micro (1 vCPU, 1GB RAM) or larger.
