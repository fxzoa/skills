# Prerequisites (`kaggle-operator`)

- **Local Tools**: Python >= 3.10, `kaggle` CLI (`~/.local/bin/kaggle`), `bash`.
- **Auth**: Valid `~/.kaggle/kaggle.json` or `KAGGLE_API_TOKEN` with write permissions for Models, Datasets, and Kernels.
- **Disk**: Sufficient local free space under `/mnt/c/Temp/` (e.g., `/mnt/c/Temp/kaggle_models/<slug>`) when staging large Public Models (20GB+).
