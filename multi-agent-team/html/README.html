Architecture & Team Protocol

multi-agent-team-skill

Antigravity環境において、Claude Codeライクなマルチモデル役割分担（Coordinator, Advisor, Reviewer, Worker）を実現し、他端末へワンコマンドで配布・適用する標準スキルパッケージ。

1. チーム編成アーキテクチャ & データフロー

各ロールがタスクの性質に応じてモデル特性（Flashの速度・Proの深層推論・Flash-Liteの並列処理力）を最大限に引き出します。

図 1.1: マルチモデル委譲アーキテクチャ（メインが統括し、必要に応じてPro/Flash-Liteを自律召喚）

2. モデル役割定義とマッピング仕様

役割 / ペルソナ 指定モデル Claude Code 対応 主な責務とトリガー
Coordinator Gemini 3.8 Flash (inherit) Claude 3.5/3.7 Sonnet 対話進行、タスク分解、メイン実装。ユーザーとの窓口。
Advisor Gemini 4 Carbon (pro) Claude 3.7 / Fable / Opus アーキテクチャ設計、方式比較、複雑な要件の壁打ち・意思決定。
Reviewer Gemini 4 Carbon (pro) Claude 3.7 Opus コード変更後の厳格なセキュリティ・品質監査、リファクタリング検証。
Worker Gemini 4 Hydrogen (flash_lite) Claude 3.5 Haiku 大量ファイルの並列検索、データ変換、軽量な静的チェック・テスト。

3. 他端末への導入手順（GitHub配布）

別PCや新規環境でも、以下のコマンドを実行するだけでマシン全体のAntigravity環境へ自動セットアップが完了します。

方式 A: Git Clone + 自動セットアップ（推奨）

新規端末のシェルで以下を実行します：

git clone <your-repo-url>
cd multi-agent-team-skill
bash scripts/setup.sh

~/.gemini/config/rules/ および ~/.gemini/AGENTS.md へ自動配備されます。

方式 B: npx skills パッケージマネージャ

スキルマネージャを利用して導入する場合：

npx skills add <user>/multi-agent-team-skill

Antigravity のスキルディレクトリへ直接リンクされます。
