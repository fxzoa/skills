# setup-run-crawl4ai: Prerequisites & Requirements

## Runtime Requirements
- **Docker:** Docker Desktop or Docker Engine 20.10+ running.
- **Python:** Python 3.9+ (Standard library only; no pip dependencies required).
- **Network Port:** TCP port `11235` (configurable via `--port`).
- **Disk Space:** ~3 GB free space for `unclecode/crawl4ai` Docker image.

## Platform Compatibility
- **Linux (Ubuntu / Debian / RHEL)**: Fully supported.
- **Windows (WSL2 / Docker Desktop)**: Fully supported.
- **macOS (Apple Silicon / Intel)**: Fully supported via Docker Desktop.
